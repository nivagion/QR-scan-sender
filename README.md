- **Android ili iPhone, bez instalacije:** [otvori web skener](https://nivagion.github.io/QR-scan-sender/). Dopusti kameru i pritisni **Skeniraj QR**. Po želji dodaj stranicu na početni zaslon.
- **Android aplikacija:** [preuzmi APK](https://github.com/nivagion/QR-scan-sender/releases/download/v1.0.0/QR-Posalji-Android.apk), otvori datoteku na telefonu i dopusti instalaciju. Pri prvom skeniranju dopusti kameru.

Web kamera radi na HTTPS adresi GitHub Pages. iPhone aplikacija u `mobile/` još nema iOS instalacijski paket: za njega su potrebni Apple Developer račun i TestFlight/App Store distribucija.
